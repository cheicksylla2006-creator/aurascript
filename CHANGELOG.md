# Aura Script — Release notes

## 3.0.0 — In validation (not released)

Development preview based on the November 27, 2026 source version. A newer Windows candidate has been submitted for Microsoft Store certification; this does not establish availability.

### Free
- Canvas: preset print and social frames, pen, shapes, brand kit, resizing, precise alignment and PNG/PDF/SVG export.
- Batch processing: preview, document selection, stop, error log, per-document history and undo for the latest batch.
- Workflows: reusable, versioned JSON action chains with built-in examples and launch-time settings.
- Export presets: formats, naming, optional watermarks and AI provenance.
- Encrypted versioned backup: user-selected folder, retention and restore preview with duplicate choices.
- Aurora: new internal Canvas and automation tools.

### Pro — not on sale
- Advanced document analysis and side-by-side document/version comparison with HTML export.
- Limited previews without a license.
- Planned price: US$15 once, individual license for up to three devices. Sales remain closed; final commercial terms are pending.

### Release gates
- The external MCP tool set remains unchanged (13 tools); internal Aurora tools are not exposed.
- Validate Windows MSIX, multi-PDF export, external-disk backup/restore and Linux packaging before release.
- This documentation does not publish binaries or enable paid checkout.

Local documents, presentations, spreadsheets, Canvas, code and PDF; dictation, semantic search, local models and the MCP connector.
